# 🎭 Unity_bean — Mr. Bean UI Demo

![Unity Version](https://img.shields.io/badge/Unity-2022.3+-blue?logo=unity)
![Platform](https://img.shields.io/badge/Platform-Windows-orange?logo=windows)
![License](https://img.shields.io/badge/License-MIT-green)

Interaktīvs mācību projekts, kas izstrādāts Unity vidē. Projekta galvenais mērķis ir demonstrēt dažādu **Unity UI (User Interface)** elementu funkcionalitāti, izmantojot populāro tēmu "Mr. Bean".

---

## 📺 Par Projektu

Šis projekts kalpo kā praktisks piemērs tam, kā apvienot lietotāja saskarnes elementus ar spēles mehāniku, audio un fiziku. No vienkāršām pogām līdz sarežģītākai "Drag and Drop" sistēmai.

### Galvenās funkcijas:
* **Interaktīvās izvēlnes:** Pilnībā funkcionējoša galvenā izvēlne un TV aina.
* **Multivide:** Audio efektu integrācija pie darbībām.
* **Fizika:** `Rigidbody` un `Collider` izmantošana objektu mijiedarbībai.
